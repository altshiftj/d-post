# Security Policy

## Supported Versions

Security fixes should be assumed only for the latest public state of this repo
or the latest public release candidate.

## Reporting a Vulnerability

Do not publish full exploit details in a public issue.

Preferred path:

1. use the repository host's private security reporting flow if it is enabled
2. otherwise open a minimal issue without exploit details and request a private
   follow-up channel

Include:

- affected version or commit
- Windows version
- Python version
- impact summary
- reproduction steps using synthetic data only

## Public Disclosure

Please wait for maintainer acknowledgement before broad public disclosure so the
issue can be triaged and, when possible, fixed first.
